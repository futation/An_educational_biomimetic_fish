# 一种教育型仿生鱼

一种教育型仿生鱼，用于学生或者极客上手体验。

基于 Arduino Nano 的蓝牙遥控仿生机器鱼：3D 打印外壳 + 自焊 PCB + 防水舵机鱼尾，全套设计开源，适合作为中小学生与电子 DIY 爱好者的手工/电子入门项目。

English documentation: see [`使用说明（英文版）/`](使用说明（英文版）/Getting%20Started.md)

## 功能特点

- 蓝牙遥控：BLE / SPP 双模串口透传，手机发指令即可控制
- 多档摆动控制：±15° / ±30° / ±45° 摆幅，低速 / 高速两档，支持鱼尾回中与持续左右摆动
- 中位角度可通过指令调节，掉电保存于 EEPROM
- 全套开源：源码、PCB 工程、3D 打印外壳、组装与使用教程

## 快速上手

1. **组装**：3D 打印外壳，按 [组装说明](组装说明/仿生鱼V1.md) 完成备料、PCB 焊接、舵机安装与配重
2. **烧录**：安装 Arduino IDE，打开 `Code/fish/fish.ino`，开发板选 Arduino Nano，按文档处理烧录时的蓝牙占用问题
3. **连接**：手机安装 [`软件/蓝牙调试器_v1.95.apk`](软件/蓝牙调试器_v1.95.apk)（第三方软件，版权归原作者所有），磁铁开启小鱼电源后蓝牙连接
4. **控制**：发送 `CMD_a` / `CMD_A` 等指令让鱼游起来，详见 [使用说明](使用说明/鱼上手说明.md) 与 [控制命令说明](使用说明/鱼控制命令说明.md)

## 开发环境

- 主控：Arduino Nano（ATmega328P），Arduino IDE + Servo 库
- 蓝牙：DX-BT04 双模透传模块（建议选带 BLE 协议的型号）
- EDA：立创EDA专业版（直接打开 `PCB/PCB.epro2`）
- 外壳：通用 FDM 3D 打印机，STEP 格式可直接导入切片/建模软件
