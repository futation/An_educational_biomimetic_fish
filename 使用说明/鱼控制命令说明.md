小鱼一共有三种操作模式：基础模式，中心校准模式，自定义模式

小鱼上电打开后 自动 进入基础模式

***

### 1. 基础模式（默认模式）

> 基础模式为默认游动模式，用于直接控制鱼的运动
>
> 向鱼发送CMD_D’，‘CMD_E’可进入其他两个调试模式

- **功能**：执行预设动作（回中、左右转、固定幅度摆动）；
- **进入方式**：系统上电默认进入，或在其他模式下发送`X`返回。

| 命令    | 功能描述         |
| ------- | ---------------- |
| `CMD_S` | 舵机回归中心位置 |
| `CMD_R` | 舵机持续右方摆动 |
| `CMD_L` | 舵机持续左方摆动 |
| `CMD_a` | ±15°摆动（低速） |
| `CMD_A` | ±15°摆动（高速） |
| `CMD_b` | ±30°摆动（低速） |
| `CMD_B` | ±30°摆动（高速） |
| `CMD_c` | ±45°摆动（低速） |
| `CMD_C` | ±45°摆动（高速） |

***

> 这个模式用于校准舵机中心位置
>
> 虽然已经调好舵机中心位置为90度
>
> 但是时间久了可能会有偏差，所以，利用这个模式来确定鱼尾在中心的时，舵机为多少度

### 2. 中心设置模式

- **功能**：自定义舵机的中心位置（默认中心可通过此模式校准）；
- **进入方式**：在基础模式下发送`CMD_D`。

| 操作                          | 功能描述                 | 限制条件                                  |
| ----------------------------- | ------------------------ | ----------------------------------------- |
| 输入数字（`CMD_0`-`CMD_180`） | 设置舵机当前角度为新中心 | 角度需在0-180度范围内，超出范围会提示错误 |
| 发送`CMD_X`                   | 返回基础模式             | 退出前会清空残留输入，避免干扰            |

**注意：**设置的角度将会被主控芯片闪存记忆，下次通电的时候，中心角度依旧是上次设置的值。

***

> 确定好鱼的中心是多少度的时候，我们就可以根据这个位置来控制摆动
>
> 这个模式我们可以选择舵机持续在两个指定的角度摆动
>
> 延时可以理解为，舵机每动一度，延时多少毫秒。这个值越大，鱼尾摆动速度越慢。

### 3. 自定义模式

- **功能**：自由设定舵机摆动的角度范围和每步延迟时间；
- **进入方式**：在基础模式下发送`CMD_E`。

#### 输入格式1

注意需发送逗号以分隔的三个参数：`CMD_角度1,角度2,延时ms`  
- **角度1/角度2**：舵机摆动的两个端点角度（如70和110，舵机会在70°与110°之间往返）；  
- **延时ms**：舵机从一个角度移动到另一个角度的每步间隔时间（影响摆动速度）。

#### 参数限制

- 角度：0-360度（超出范围会提示错误）；  
- 延时：1-1000ms（过小可能导致舵机卡顿，过大会降低响应速度）。

#### 操作命令
| 操作                      | 功能描述                                 |
| ------------------------- | ---------------------------------------- |
| 发送参数（如`70,110,20`） | 按设定角度和延时循环摆动，直到发送新命令 |
| 发送`X`                   | 返回基础模式，停止当前摆动               |

**示例**：  
发送`CMD_70,110,20` → 串口显示“✅ 自定义摆动: 70° ↔ 110°, 延时20ms”，舵机开始往返摆动；  
发送`CMD_0,180,500` → 舵机在0°到180°之间缓慢摆动，每步间隔500ms。

***

#### 输入格式2

> 对比真鱼：鱼的尾巴不是不间断，摆动几下，鱼就会停下来休息的
>
> 自定义模式下支持模仿鱼的停止时间

注意需发送以逗号分隔的五个参数：`CMD_角度1,角度2,延时ms,摆动周期,停止时间`  

- **角度1/角度2**：舵机摆动的两个端点角度（如70和110，舵机会在70°与110°之间往返）；  
- **延时ms**：舵机从一个角度移动到另一个角度的每步间隔时间（影响摆动速度）。
- **摆动周期**：舵机摆动的周期
- **停止时间**：完整N个周期（N是上一个参数）之后，停止的时间，单位是ms

#### 操作命令

| 操作                                 | 功能描述                                                     |
| ------------------------------------ | ------------------------------------------------------------ |
| 发送参数（如`CMD_70,110,20,3,2000`） | 在70和110度之间摆动，步近延时15ms（控制速度），摆动3个周期后，会停止2秒，然后继续摆动3个周期... |
| 发送`CMD_X`                          | 返回基础模式，停止当前摆动                                   |
